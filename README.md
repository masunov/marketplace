# Marketplace

**Стек:** PHP 8.4, Laravel 13, PostgreSQL 17, Redis 7, очередь под управлением Horizon.

Эквайринга и реальных поставщиков нет — и платёжная система, и два поставщика реализованы
заглушками внутри проекта.

---

# Запуск

```bash
docker compose up -d --build
```
Внешний порт `8585` и `54322` должены быть свободны

Документация по API, запуск и прогон тестов в `DESCRIPTION.md` и `DESCRIPTION_PART_2.md`
